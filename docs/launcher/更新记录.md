# 0.5.0 · SCUM 界跃 / SCUM Rift · 2026-11-12

- 新增一键“切换纯净模式／恢复 MOD 模式”：将 ~Mods、LogicMods 和标准 UE4SS 环境暂存到游戏根目录的 `.SCUMRift-cache`，不用卸载、重新下载或复制整份模组。
- 同时保留手动文件、配置与原启用状态；游戏运行禁止切换，纯净模式禁止导入和修改模组。
- 加入切换清单、哈希核对、同名文件保护、取消回滚、进程中断恢复、重解析点拒绝和缓存记录校验。恢复目标有新文件时保留两边并提示处理。
- Steam 启动改为客户端路径、同会话界面进程、账号及短暂连续稳定检测；每 150ms 检查，稳定约 600ms 后放行，最多 120 秒且可取消，不再超时后直接启动游戏。
- Steam 等待与模组完整性检查并行，启动前再次核对状态；纯净模式不追加 MOD 启动参数。
- 统一窗口启动入口，旧 launcher.ps1 的启动能力停用，保留只读诊断。
- 全新品牌与多尺寸图标：青色与琥珀色双门表达 MOD／纯净模式切换；同步更新五种语言。
- 标准目录缓存不能还原已覆盖的官方资源；降级或移动游戏目录前，先用本版恢复 MOD。真实 Steam 冷启动与游戏兼容性仍需实际游玩验证。

# 0.4.0 · 2026-11-12

- 新增 UE4SS C++ DLL 模组拖入安装：检查原生 x64 格式与模组导出，命名 DLL 自动规范为 Mods/模组名/dlls/main.dll；单独 main.dll 支持名称提示。
- 识别 Win64 根目录与 ue4ss 子目录两种 UE4SS 布局，显示检测状态和模组目录入口；缺少时提示导入完整兼容离线包，不联网自动获取。
- 标准结构的依赖 DLL、配置和资源随压缩包安装；自动管理 mods.txt，保留无关启用项与注释，处理 enabled.txt 绕过标记。
- DLL 模组支持禁用、启用、更新、上一版回滚和卸载原件恢复；离线环境、DLL 和 PAK 同批提交并可中断恢复。
- 增加 UE4SS 导入符号检查、原件备份、外部手动改动保护、加载环境依赖保护、脚本/路径/文件数量限制与客户端服务端包识别。
- 简体中文、繁体中文、英文、日文、韩文同步补齐新功能文案。
- 保持现有 Steam 行为；模组托管和在线下载方式尚未接入。
- 这是功能仍在完善的社区测试版，当前主要用于启动已安装 MOD 的游戏；未宣称完成真实游戏内注入兼容验证。

# 0.3.0 · 2026-11-09

- 新增简体中文、繁体中文、英文、日文、韩文切换：设置页选择后立即生效，记住选择；首次跟随 Windows 界面语言，其他系统语言使用英文。
- 翻译主要页面、按钮、主题名、拖入提示、安装进度与结果、操作确认和启动器错误；模组作者内容、文件名、路径保留原文，Windows 原生弹窗按钮随系统显示。
- 语言与主题共同保存且互不覆盖；筛选与安装状态判断独立于界面语言。任务执行期间暂不能更改语言，既有日志保留生成时的语言。
- 新增整个窗口接收 PAK、ZIP、7Z、RAR 拖入，显示拖放提示并自动识别、解压、校验、安装。
- 导入按钮支持多选文件；压缩包中的多层目录自动识别，只安装 PAK。
- 多文件使用同一事务提交，故障或进程中断后整体恢复，避免只安装一半。
- 新增压缩路径、链接、重复文件、CRC、解压大小与数量检查，拒绝加密/分卷及伪装格式；支持取消和暂存清理。
- 保留手动同名文件确认备份、原件恢复、旧版回滚、已禁用状态和游戏运行保护。
- 新增 SharpCompress 1.0.0，客户端无需另外安装解压软件，许可见第三方许可。
- Steam 服务保持原样，Steam 窗口仅翻译显示文案，账号与启动判断行为保持原样；线上托管方式尚未接入。

# 0.2.0 · 2026-11-09

- 重建路径、清单、配置、文件校验与安装管理核心；修复此前隔离审查复现的 11 类问题。
- 增加安装事务、崩溃恢复、上一版回滚、跨进程目录锁、游戏运行写入保护。
- 增加本地 PAK 导入、启停、卸载、完整性检查及未纳管文件识别。
- 增加依赖、已知冲突、游戏版本范围检查；不宣称自动识别所有内部资源冲突。
- 增加本地签名发行工具、内嵌发行公钥、已验证清单缓存及离线发行包验证。
- 增加超时、取消、有限重试、备用源切换、受校验的 Range 续传和重定向限制。
- 增加路径选择、搜索筛选、跨页面进度、文件日志、诊断导出及恢复入口。
- 配置、主题、日志和缓存迁至用户数据目录，原版种子保留迁移备份。
- 迁移至 .NET 10，提供自带运行环境的 Windows x64 发行包。
- Steam 相关服务和窗口处理方法沿用原版；模组托管、正式下载地址与在线更新仍待决定。

实际测试记录与剩余条件见随项目交付的验收报告。此版本为社区预览版，尚未完成真实玩家规模与所有游戏版本的兼容性验证。

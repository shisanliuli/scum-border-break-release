## 它能做什么

| | 原版 SCUM | 装完这个 mod |
|---|---|---|
| 岛屿边界石墙（北端、东端） | 一堵看不见顶的实体墙，翻不过去 | **完全消失**，可以自由飞出去 |
| 越过地图边界 | **约 14 秒后直接判死**（不扣血，是硬判死，任何护甲/减伤都拦不住） | **不再判死**，想在外面待多久都行 |
| 出界时的持续掉血 | 有 | 已关闭 |
| 掉到极深的位置 | 会被压死 | 放宽到极深也不会死 |

## 安装（3 步）

1. 把 `pak/` 里的**两个** `.pak` 文件复制到：
   ```
   ...\steamapps\common\SCUM\SCUM\Content\Paks\~Mods\
   ```
   （`~Mods` 文件夹没有就自己新建一个）

2. **必须带 `-fileopenlog` 参数启动游戏。**
   否则游戏会校验 pak 签名，然后拒绝加载并直接退出。

   在 Steam 里设置：库 → SCUM 右键 → 属性 → 启动选项，填：
   ```
   -fileopenlog
   ```

3. 进存档即可。走到地图最北端或最东端，往外飞。

### 卸载

删掉这两个 `.pak` 就恢复原版行为。**它不改存档，随时可以装/卸。**

## 常见问题

**Q：进游戏直接闪退 / 提示 pak 签名无效？**
A：忘了加 `-fileopenlog` 启动参数。见上面第 2 步。

**Q：墙还在？**
A：检查 `~Mods` 里是否同时留着别的同类 pak（名字里带 `NoOOB` / `NoWall`），
或者确认文件确实放进了 `~Mods` 而不是 `Paks` 根目录。

**Q：界外有什么？**
A：目前**只有海面和虚空**，没有新地形。这个 mod 解决的是"能不能出去"，不是"外面有没有内容"。
（后续如果加了地图外区域，会在这个仓库更新。）

**Q：联机能用吗？**
A：这是**客户端资产替换**，只在单机 / 自己开的存档有效。官方联机服务器不认这组 pak，
能不能用取决于服务器规则——请自行判断，别拿去破坏别人的服务器。

**Q：游戏更新后失效了？**
A：有可能。游戏更新可能改动相关资产结构，届时需要重新制作。留意本仓库的更新。

**Q：会不会封号？**
A：单机自己玩不涉及。**不要在有其他玩家的官方服务器上使用。**

Windows 校验命令（PowerShell）：
```powershell
Get-FileHash .\pakchunk962-NoWall_P.pak -Algorithm SHA256
```

两个包的编号（962 / 966）**不要改**。SCUM 按文件名字母序决定覆盖优先级，改编号可能导致被别的 mod 盖掉。
